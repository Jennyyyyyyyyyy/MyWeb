畢業專題

智能辨識存錢筒

2024.03 – 2025.03｜影像辨識與硬體整合

  1. 以 Jetson Nano 作為邊緣運算平台，開發即時影像辨識功能。
  2. 蒐集與標註台幣、日幣硬幣資料，以 YOLOv5 + PyTorch 完成模型訓練。
  3. 使用 OpenCV 進行影像前處理，提升辨識效率與準確率。
  4. 以 CUDA / cuDNN 加速 GPU 推論，實現低延遲即時辨識。
  5. 串接 Firebase，讓辨識結果即時上傳並與 App 同步。
  6. 控制伺服馬達設計硬幣投入開關機構，提升互動體驗。
  • Jetson Nano
  • YOLOv5
  • PyTorch
  • OpenCV
  • CUDA / cuDNN
  • Firebase
  • 伺服馬達
